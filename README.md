journaling, deal hunting, document design. My tools run **locally**, keep **a human approving
every action that matters**, and use AI only where it earns its place.

## 🧭 How I work

- **Local-first.** Your data stays on your machine unless a feature explicitly needs the network.
- **Human in the loop.** Agents draft; people approve. Nothing irreversible happens silently.
- **Decisions on paper.** Non-trivial projects ship with ADRs explaining *why*, not just *what*.
- **Proof over claims.** Tests, real screenshots, and a secret scan before anything goes public.
